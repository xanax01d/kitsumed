Мы шчыра вітаем пераклады ад супольнасці! Калі вы хочаце дадаць нацыянальную мову (нямецкую, іспанскую, французскую, польскую, украінскую і г. д.) ці атмасферную тэматычную персону (фэнтэзі, рэтра, sci-fi) — гэта кіраўніцтва дапаможа інтэграваць вашу лакалізацыю ў KitsuMed.

## 🚀 Хуткі старт (5 крокаў)

1. **Зрабіце форк рэпазіторыя** на GitHub: `https://github.com/xanax01d/kitsumed`.
2. **Скапіюйце шаблон ці эталонны файл англійскай лакалізацыі**:
   ```bash
   cp locales/en.json locales/<код_мовы>.json
   # Прыклад: cp locales/en.json locales/pl.json
   ```
   *Выкарыстоўвайце стандартны 2-літарны [код ISO 639-1](https://en.wikipedia.org/wiki/List_of_ISO_639-1_codes) (напрыклад, `de`, `es`, `fr`, `pl`, `uk`, `ja`).*

3. **Перакладзіце радкі** ўнутры створанага файла `locales/<код_мовы>.json`.
4. **Праверце пераклад аўтаматычным валідатарам**:
   ```bash
   python scripts/validate_locale.py locales/<код_мовы>.json
   ```
5. **Стварыце Pull Request** у галіну `dev`!

## 📂 Структура файлаў лакалізацыі

Кожны файл лакалізацыі з'яўляецца адзіным дакументам JSON у кадзіроўцы UTF-8, які змяшчае метададзеныя і 6 раздзелаў перакладу:

```json
{
  "meta": {
    "code": "pl",
    "name": "🇵🇱 Polski"
  },
  "messages": { ... },
  "location_map": { ... },
  "pain_type_map": { ... },
  "symptoms_map": { ... },
  "medication_map": { ... },
  "triggers_map": { ... }
}
```

### 0. `meta` (Метададзеныя лакалізацыі)
- `code`: Унікальны ідэнтыфікатар мовы ў ніжнім рэгістры, які супадае з імем файла (напрыклад, `"pl"`, `"de"`, `"fr"`).
- `name`: Назва мовы з эмодзі сцяга для кнопкі выбару ў меню (напрыклад, `"🇵🇱 Polski"`). KitsuMed дынамічна рэндэрыць гэтую кнопку ў меню `/language` без неабходнасці перакампіляцыі бота!

### 1. `messages` (Тэксты інтэрфейсу і дыялогаў)
Змяшчае ўсе сістэмныя падказкі, кнопкі навігацыі, абвесткі і загалоўкі справаздач.
- **Зменныя / Плэйсхолдары**: Некаторыя радкі змяшчаюць зменныя віду `{id}`, `{time}`, `{dur}`, `{count}`. **НЕ перакладайце імёны зменных усярэдзіне `{}`**, захоўвайце іх дакладна:
  ```json
  "saved_completed_text": "Эпізод <b>#{id}</b> пазначаны як завершаны ({dur})."
  ```
- **Telegram Rich UI (TG-13)**: Радкі могуць змяшчаць спецыяльныя інтэрактыўныя тэгі Telegram:
  - `<tg-button-row>` і `<tg-button type="callback_data" data="...">Тэкст кнопкі</tg-button>`
  - `<blockquote expandable>Згортвальны дадатковы тэкст</blockquote>`
  - Стандартнае HTML-фарматаванне: `<b>тлусты</b>`, `<i>курсіў</i>`, `<code>код/дазіроўка</code>`.

### 2. `location_map` (Лакалізацыя цэфалгіі)
Адпаведнасць анатамічных абласцей (напрыклад: `forehead`, `temples`, `back_of_head`, `left`, `right`, `bilateral`, `diffuse`).

### 3. `pain_type_map` (Характар болю)
Клінічныя характарыстыкі болю (напрыклад: `throbbing`, `pressing`, `stabbing`, `dull`).

### 4. `symptoms_map` (Спадарожныя сімптомы)
Крытэрыі мігрэні паводле ICHD-3 (напрыклад: `nausea`, `vomiting`, `photophobia`, `phonophobia`, `aura`, `dizziness`).

### 5. `medication_map` (Медыкаменты)
Прадвызначаныя прэпараты з тыповымі тэрапеўтычнымі дазіроўкамі.

### 6. `triggers_map` (Правакацыйныя трыгеры)
Ключавыя трыгеры цэфалгіі (напрыклад: `stress`, `lack_of_sleep`, `oversleep`, `weather`, `alcohol`, `skip_food`).

## 🦊 (Апцыянальна) Даданне банэра-маскота

Кожная лакалізацыя ў KitsuMed суправаджаецца унікальным стылізаваным анімэ-маскотам (лісічкай-кіцунэ), які перадае нацыянальны каларыт або атмасферу тэмы!

Калі вы хочаце намаляваць ці згенераваць маскота для вашай мовы:
1. Фармат: **гарызантальная выява 16:9** (`1376x768` ці `1280x720`).
2. Шлях у праекце: `assets/images/<код_мовы>/hero_banner.png`.
3. Стылістыка: Утульны анімэ-арт (у стылістыцы Kyoto Animation / Makoto Shinkai), мілая лісічка з пухнатымі вушкамі і хвосцікам у строі, які адлюстроўвае культуру ці сэтынг.
*Калі ў мовы няма свайго банэра, бот аўтаматычна выкарыстоўвае эталонны англійскі банэр.*

## 🔍 Скрыпт валідацыі

Перад адпраўкай Pull Request абавязкова запусціце валідатар:

```bash
# Валідацыя канкрэтнага файла
python scripts/validate_locale.py locales/<код_мовы>.json

# Або праверка ўсіх лакалізацый праекта
python scripts/validate_locale.py
```

Валідатар аўтаматычна правярае:
- Карэктнасць сінтаксісу JSON.
- Наяўнасць абавязковага блока `meta` (`code` і `name`).
- Прысутнасць усіх абавязковых ключоў паводле эталона `en.json`.
- Адсутнасць пустых радкоў перакладу.
- Захаванасць усіх шаблонаў і зменных (`{id}`, `{time}` і г. д.).
