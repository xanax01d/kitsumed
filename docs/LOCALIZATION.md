---

## 🚀 Быстрый старт (5 шагов)

1. **Сделайте форк репозитория** на GitHub: `https://github.com/xanax01d/kitsumed`.
2. **Скопируйте шаблон или эталонный файл английской локализации**:
   ```bash
   cp locales/en.json locales/<код_языка>.json
   # Пример: cp locales/en.json locales/de.json
   ```
   *Используйте стандартный 2-буквенный [код ISO 639-1](https://en.wikipedia.org/wiki/List_of_ISO_639-1_codes) (например, `de`, `es`, `fr`, `pl`, `uk`, `ja`).*

3. **Переведите строки** внутри созданного файла `locales/<код_языка>.json`.
4. **Проверьте перевод автоматическим валидатором**:
   ```bash
   python scripts/validate_locale.py locales/<код_языка>.json
   ```
5. **Создайте Pull Request** в ветку `dev`!

## 📂 Структура файлов локализации

Каждый файл локализации представляет собой единый JSON-документ в кодировке UTF-8, содержащий блок метаданных и 6 разделов перевода:

```json
{
  "meta": {
    "code": "de",
    "name": "🇩🇪 Deutsch"
  },
  "messages": { ... },
  "location_map": { ... },
  "pain_type_map": { ... },
  "symptoms_map": { ... },
  "medication_map": { ... },
  "triggers_map": { ... }
}
```

### 0. `meta` (Метаданные локализации)
- `code`: Уникальный идентификатор языка в нижнем регистре, совпадающий с именем файла (например, `"de"`, `"fr"`, `"pl"`).
- `name`: Название языка с эмодзи флага для кнопки выбора в меню (например, `"🇩🇪 Deutsch"`). KitsuMed динамически отображает эту кнопку в меню `/language` без необходимости перекомпиляции бота!

### 1. `messages` (Тексты интерфейса и диалогов)
Содержит все системные подсказки, кнопки навигации, оповещения и заголовки отчетов.
- **Переменные / Плейсхолдеры**: Некоторые строки содержат подстановочные знаки вида `{id}`, `{time}`, `{dur}`, `{count}`. **НЕ переводите имена переменных внутри `{}`**, оставляйте их как есть:
  ```json
  "saved_completed_text": "Приступ <b>#{id}</b> отмечен как завершенный ({dur})."
  ```
- **Telegram Rich UI (TG-13)**: Строки могут содержать специальные интерактивные теги Telegram:
  - `<tg-button-row>` и `<tg-button type="callback_data" data="...">Текст кнопки</tg-button>`
  - `<blockquote expandable>Сворачиваемый дополнительный текст</blockquote>`
  - Стандартное HTML-форматирование: `<b>жирный</b>`, `<i>курсив</i>`, `<code>код/дозировка</code>`.

### 2. `location_map` (Локализация цефалгии)
Сопоставление анатомических областей (например: `forehead`, `temples`, `back_of_head`, `left`, `right`, `bilateral`, `diffuse`).

### 3. `pain_type_map` (Характер боли)
Клинические характеристики боли (например: `throbbing`, `pressing`, `stabbing`, `dull`).

### 4. `symptoms_map` (Сопутствующие симптомы)
Критерии мигрени по ICHD-3 (например: `nausea`, `vomiting`, `photophobia`, `phonophobia`, `aura`, `dizziness`).

### 5. `medication_map` (Медикаменты)
Предустановленные препараты с типовыми терапевтическими дозировками.

### 6. `triggers_map` (Провоцирующие триггеры)
Ключевые триггеры цефалгии (например: `stress`, `lack_of_sleep`, `oversleep`, `weather`, `alcohol`, `skip_food`).

## 🦊 (Опционально) Добавление баннера-маскота

Каждая локализация в KitsuMed сопровождается уникальным стилизованным аниме-маскотом (лисичкой-кицунэ), передающим национальный колорит или атмосферу темы!

Если вы хотите нарисовать или сгенерировать маскота для вашего языка:
1. Формат: **горизонтальное широкоформатное изображение 16:9** (`1376x768` или `1280x720`).
2. Путь в проекте: `assets/images/<код_языка>/hero_banner.png`.
3. Стилистика: Уютный аниме-арт (в стиле Kyoto Animation / Makoto Shinkai), милая лисичка с пушистыми ушками и хвостиком в костюме, отражающем культуру или тематику.
*Если у языка нет собственного баннера, бот автоматически использует эталонный английский баннер.*

## 🔍 Скрипт валидации

Перед отправкой Pull Request обязательно запустите валидатор:

```bash
# Валидация конкретного файла
python scripts/validate_locale.py locales/<код_языка>.json

# Или проверка всех локализаций проекта
python scripts/validate_locale.py
```

Валидатор автоматически проверяет:
- Корректность синтаксиса JSON.
- Наличие обязательного блока `meta` (`code` и `name`).
- Присутствие всех обязательных ключей по эталону `en.json`.
- Отсутствие пустых строк перевода.
- Сохранность всех шаблонов и переменных (`{id}`, `{time}` и т. д.).
